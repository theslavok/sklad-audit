# Склад-аудит

Веб-чек-лист для аудита складских процессов (сырьё / полуфабрикаты / готовая продукция, учёт остатков в 1С).

Рабочая ссылка: https://theslavok.github.io/sklad-audit/

При каждом открытии сайта показывается стартовый экран: **новый аудит**, опционально продолжить локальный черновик или открыть сохранённый аудит по коду/ссылке.

Чтобы результаты были доступны другим участникам по ссылке (не только в одном браузере), настройте бесплатное облако Supabase — инструкция в **SETUP-CLOUD.md**. После настройки кнопка «Сохранить текущий аудит» выдаёт код и ссылку вида `…/sklad-audit/?a=КОД`.

## Локальный запуск

Нужен любой статический сервер (сайт не открывается как `file://`).

```bash
npx --yes serve .
```

или

```bash
python -m http.server 5173
```

## Деплой

GitHub Pages: репозиторий https://github.com/theslavok/sklad-audit → Settings → Pages → branch `main` / `/`.

Также есть `vercel.json` и `netlify.toml`.

## Интерфейс

| Вкладка | Назначение |
|--------|------------|
| Склады | Имена складов, аудитор, дата |
| Пре-опрос | Вопросы → н/п и усиление пунктов |
| Обход | Чек-лист с фильтрами |
| Сводка | Сравнение складов, разрывы, сохранение со ссылкой |
| История | Общие (облако) или локальные сохранённые аудиты |

## Файлы

- `index.html`, `styles.css`, `app.js`, `data.js` — сайт
- `cloud-config.js`, `cloud.js`, `SETUP-CLOUD.md` — общее хранение по ссылке
- `checklist-data.json` — пункты чек-листа
