# Склад-аудит

Веб-чек-лист для аудита складских процессов (сырьё / полуфабрикаты / готовая продукция, учёт остатков в 1С).

Откройте сайт по ссылке → заполните пре-опрос и обход → при необходимости скачайте CSV. Данные аудита хранятся в браузере (localStorage). Логина нет: у кого есть ссылка, тот может пользоваться. Для передачи результатов между ПК используйте **экспорт/импорт JSON**.

## Локальный запуск

Нужен любой статический сервер (из‑за `fetch` файла данных сайт не открывается как `file://`).

Если есть Node.js:

```bash
npx --yes serve .
```

Или Python 3:

```bash
python -m http.server 5173
```

Откройте `http://localhost:5173` (или порт, который покажет `serve`).

## Деплой в облако (бесплатно)

### Vercel

1. Зарегистрируйтесь на [vercel.com](https://vercel.com)
2. Import Git Repository **или** CLI: `npx vercel` в этой папке
3. Root Directory — корень проекта, Framework Preset — **Other**
4. После деплоя получите ссылку вида `https://….vercel.app`

В репозитории уже есть `vercel.json`.

### Netlify

1. [netlify.com](https://www.netlify.com) → Add new site → Deploy manually **или** Git
2. Publish directory: `.` (корень)
3. Либо CLI: `npx netlify deploy --prod --dir=.`

Есть `netlify.toml`.

### GitHub Pages

1. Создайте репозиторий, загрузите файлы
2. Settings → Pages → Source: Deploy from branch `main` / folder `/` (root)
3. Сайт будет на `https://<user>.github.io/<repo>/`

Если репозиторий не в корне домена, пути `./checklist-data.json` и `./app.js` остаются относительными — ок.

## Что в интерфейсе

| Вкладка | Назначение |
|--------|------------|
| Склады | Имена складов, аудитор, дата |
| Пре-опрос | 12 вопросов → н/п и усиление пунктов |
| Обход | Чек-лист с фильтрами |
| Сводка | Сравнение складов и разрывы для SOP |

Кнопки сверху: **CSV**, **резервная копия JSON**, **импорт JSON**.
